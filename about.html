Data Source

This project uses the FHFA House Price Index (HPI) dataset published by the Federal Housing Finance Agency (FHFA).

The FHFA HPI is a collection of publicly available house price indexes that measures changes in single-family home values across the United States. The dataset includes information for different geographic levels, including the United States, Census Divisions, states, metropolitan areas, counties, and other areas. The project uses variables such as geographic location, year, period, index type, and housing price index values to examine patterns over time. :contentReferenceoaicite:2

About the Analysis

The analysis in this website focuses on describing patterns found in the data.

The project examines:

  • Housing price index changes over time
  • Differences between geographic regions
  • Annual averages
  • Variation within years
  • The structure of the underlying dataset

The visualizations are created using R, ggplot2, tidyverse, and Quarto.

## Data Source

This project uses the **FHFA House Price Index (HPI)** dataset published by the **Federal Housing Finance Agency (FHFA)**.

The FHFA HPI is a collection of publicly available house price indexes that measures changes in single-family home values across the United States. The dataset includes information for different geographic levels, including the United States, Census Divisions, states, metropolitan areas, counties, and other areas. The project uses variables such as geographic location, year, period, index type, and housing price index values to examine patterns over time. :contentReference[oaicite:2]{index=2}
